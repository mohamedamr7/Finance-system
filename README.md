# financialAI Analysis: Offline Multi-Agent Financial Intelligence System

An offline, privacy-first multi-agent financial analysis platform designed to process unstructured corporate financial data (PDFs) and provide deterministic mathematical calculations, analytical reports, and predictive trend forecasts. 

This project is developed as a thesis submission to meet the evaluation requirements of **Dr. Gamal**.

##  What to Download & Install

To run this system fully offline on your local machine, you must download the following components:

### 1. Python Environment
* Download and install **Python 3.10+** (or Python 3.14) from the official [Python website](https://www.python.org/downloads/). 
* *Make sure to check the box that says "Add Python to PATH" during the installation setup.*

### 2. Ollama & The Llama 3 Model
* Download and install the **Ollama Desktop Application** for your operating system from [Ollama's official website](https://ollama.com/download).
